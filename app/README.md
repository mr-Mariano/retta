# Retta web app

Next.js (App Router, TypeScript, Tailwind CSS v4) with Supabase. See the repository README for setup and deployment.

- Design tokens in `src/app/globals.css` mirror the Figma `Color` collection (dark first).
- Fonts: Big Shoulders (optical size, Display cut at large sizes) for titles and numbers, Geist for text.
- Supabase clients: `src/lib/supabase/client.ts` (browser) and `src/lib/supabase/server.ts` (server).
